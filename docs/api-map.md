> 路径均**不含** `/web-api` 前缀：前端请求拦截器会统一加上，
> 所以实际请求路径是 `/web-api` + 下表路径。
> 带 `${...}` 的是路径参数（拼在 URL 里），其余走 query（GET）或 body（POST/PUT）。
